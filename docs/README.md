## 文档生命周期

文档记录已完成的功能基线，不追踪每次开发改动。功能开发期间允许实现暂时领先于文档；在一项功能完成、阶段交付或用户要求集中整理时，统一更新相关文档及其校准信息。日常修复、内部重构和实验性调整不要求同步维护文档。

“最近校准”表示正文最近一次与对应功能实现集中核对，不是文件最后编辑时间，也不表示业务验收通过。日期不作为过期判定；功能节点按可独立使用、可以交付的功能划分，不按 commit 划分。开发中的最新行为以当前代码为准。

本轮按 **1.0.0** 校准，日期为 **2026-11-12**。现行文档覆盖使用、部署、管理与开发。历史快照保留原日期与结论。`prompts/*.md`（README 除外）是运行时模板。
