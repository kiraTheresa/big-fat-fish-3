# 管理台人工验收清单

[← 文档目录](README.md)

本清单覆盖 `web/` 管理台与实际管理 API 的业务链。隔离浏览器检查与真实 QQ / 模型验收分开记录；下方业务清单仍用于真实环境人工验收。页面没有示例业务数据；卡片、列表和详情均读取同源 API。

## 启动与范围

1. 在本地 `.env` 设置随机 `ADMIN_TOKEN`，至少 24 个字符；不要把令牌写入文档、聊天或 URL。
2. 使用 `npm start` 启动 Bot。默认管理地址为 `http://127.0.0.1:3210`，以启动日志中实际端口为准。
3. 在页面输入管理令牌。验证成功后在当前浏览器记住登录 30 分钟，期间刷新或重新打开会自动验证令牌并进入；刷新不续期。退出、到期或 401 会清除记录。浏览器禁用存储时退回只保留页面内存，并显示提示。
4. 当前网页是 QQ Bot 的本地控制台，功能包含概览、配置、Prompt、素材、用户权限、调度、日志、请求稳定性和用量；事件收件箱仅保留旧地址和接口。任务类型只有数据维护与记忆提炼，不提供主动发消息入口。

## 使用方式

按本次完成的功能选择相关场景，不要求每次改动执行整张表。执行结果另记日期、代码版本、环境、通过／失败和未覆盖范围；本清单本身不记录某次执行状态。历史工程和浏览器核验见 [验证汇编](archive/2026-11-04-validation-history.md)。

## 浏览器业务链

| 场景 | 操作 | 应观察到的结果 |
| --- | --- | --- |
| 登录 | 空令牌、错误令牌、正确令牌分别提交 | 空值不能提交，错误令牌明确提示；正确令牌进入运行概览。 |
| 登录记忆 | 登录后刷新、重新打开；推进到登录后 30 分钟 | 有效期内自动验证并进入，刷新不延长截止时间；到期回到登录页。 |
| 退出与过期 | 退出后尝试返回；重启 Bot 并更换令牌 | 退出清除内容、内存令牌与保存记录，其他已打开页面同步退出；旧令牌收到 401 后返回登录。 |
| 真实状态 | QQ 断开/重连后点击刷新 | 明确显示未连接/重连中/已连接；不能把管理服务在线当作 QQ 在线。 |
| 今日统计 | 有真实调用后查看概览、用量页 | 概览显示北京时间当日统计；用量页默认今天，可按日期与会话筛选。失败和用量未返回分别统计。 |
| 账本不可用 | 在隔离测试环境使账本不可读后刷新概览 | 今日调用、Token、失败和图片显示“不可用”，同时显示异常；不当作零。 |
| 概览失败入口 | 查看概览与导航，打开最近失败详情 | 概览展示最近失败和发送积压；主导航没有收件箱，协议事件存储仍保留。 |
| 畸形与安全文本 | 查看含 `<script>` / HTML 文字或不完整消息段的事件 | 只显示文字，不执行 HTML；整页不会因为单个畸形段崩溃。 |
| 日志范围与翻页 | 切换仅看失败/全部日志，筛选 DEBUG/INFO/WARN/ERROR、会话与关键词；翻页与重置 | 默认失败视图排除正常跳过和策略拒绝；全部日志可查看调试和成功记录；重置恢复仅看失败，历史页不自动跳到最新。 |
| 配置保存 | 改呼唤名、延迟、能力开关与限额后保存 | 提示已保存；刷新后值保留。界面不显示密钥。后续业务行为按新配置执行。 |
| 配置校验 | 输入最长延迟小于最短延迟或超界数字 | 保存被阻止或显示服务端具体错误；编辑值保留。 |
| 分隔符兼容 | 分隔符留空或输入换行后保存，再读取 | 留空和换行均可保存；换行内容不会在表单读取时丢失。 |
| 保存中保护 | 提交配置时尝试继续编辑、重复提交或换页 | 保存期间控件锁定、不会重复提交；冲突/失败后原编辑值保留。 |
| 未保存保护 | 改配置后点其他页面、刷新按钮、重新读取、退出或关页 | 离开前提醒；取消后编辑值仍在。 |
| 配置并发 | 两个页面读取同版本，先后保存 | 第二个页面提示版本冲突并保留编辑值；重新读取需要确认放弃编辑。 |
| 用户权限 | 添加 QQ 普通/管理员/封禁角色；编辑备注；恢复默认 | 新权限立即显示；恢复默认需要确认。`ADMIN_QQ` 用户恢复默认后仍为管理员。 |
| 默认开放 | 用未配置用户尝试绘图 | 默认没有绘图白名单；仍受全局能力、封禁、额度和服务配置影响。真实调用验收会产生用量。 |
| 间隔任务 | 创建短间隔数据维护任务，观察结果，暂停再启用 | 下次执行时间更新；结果可查；暂停后不再安排新的执行。 |
| 单次任务 | 创建未来单次维护任务，执行后查看，再尝试启用 | 执行后显示已执行；再次启用会进入编辑，要求设置新时间。 |
| 任务编辑与删除 | 修改名称/间隔；删除；任务运行中尝试修改 | 编辑生效；删除确认后消失；运行中冲突显示任务错误，不误报配置冲突。 |
| 失败详情与链路 | 分别筛选 WARN/ERROR，搜工具名或错误，展开详情与本轮链路 | 结果真实；无需模型请求记录也能查看工具/发送失败链路；成功步骤保留，未知结果不显示为成功；不显示密钥。 |
| 用量筛选 | 选日期、会话、明细用途与待确认；开始日期晚于结束日期 | 查询正确；逆序日期被阻止；统计覆盖全部匹配记录，明细为最新有限条。日期按北京时间解释；用途与待确认筛选只影响明细。 |
| 请求统计 | 选择日期、用途、来源和会话，再点击时段或失败原因 | 全页筛选更新摘要；时段、原因和仅看异常只筛选明细；未知结果不计入已知失败率分母，缺失耗时不当作零。 |
| 请求快照与翻页 | 下钻、翻到更早明细，在另一个客户端产生新记录后返回 | 保持统计截止点和筛选，手动刷新才读取新快照；链路可分页，旧记录无关联 ID 时说明不可关联。 |
| 费用完整性 | 混合已计价、无价目与缺少 usage 的记录 | 明确区分已计价与待确认，未知费用不当作零；账本读取失败显示错误。 |
| 网页分享图片 | 固定日期与会话生成预览，再下载；使快照过期后重试 | 预览与下载使用同一 PNG；统计取页面快照，过期提示刷新；不含 QQ 号、调用明细和管理操作。 |
| QQ 用量报告 | 在测试群／私聊执行 `/usage today` 或自然语言请求 | 只统计当前会话；按平台确认展示结果，失败或未知不自动补发；控制台沙盒不读取真实账本或发送 QQ。 |
| 截图不可用 | 在隔离环境使用无效浏览器路径或使任务队列满载 | 浏览器不可用返回 503，满载返回 429；页面显示错误，不伪造报告成功。 |
| Prompt 与素材 | 按各专题完成草稿发布或素材浏览操作 | Prompt revision、沙盒和工具范围见 [Prompt 清单](prompt-console.md#验收场景)；素材下载与动画限制见 [媒体说明](media-storage.md#管理台浏览与下载)。 |
| 自动更新 | 勾选每 20 秒更新；切到后台或编辑筛选输入 | 最新页自动更新；后台、详情弹窗、历史页和正在输入时暂停自动更新。配置不自动覆盖。 |
| 网络失败 | 页面打开后停止管理服务，再刷新 | 显示连接错误与重试；不会显示虚构成功状态。 |
| 移动端 | 375 px、768 px、1440 px 视口检查 | 小屏导航横向滚动，卡片重排；表格在自身容器内滚动，页面不横向溢出。 |
| 键盘与动效 | Tab 导航、Enter 提交、Esc 关闭详情；系统减少动态效果 | 控件有焦点提示；弹窗关闭回到原操作；减少动态效果时禁用旋转与过渡。 |

## 实现约束参考

- 开发阶段功能优先：灰白实色面板、清晰边框、紧凑表格，蓝色标识选中项与主要操作。导航按运行排查、开发调试、实例管理分组。没有外部素材、字体或图片依赖。
- `index.html` 提供登录页与稳定布局；`app.js` 管理路由、真实 API、表单与错误状态；`styles.css` 管理响应式样式。
- API 动态内容统一 HTML 转义，JSON 详情作为文本展示。静态站点兼容 `script-src 'self'; style-src 'self'`。
- 状态刷新具有请求序号保护，避免旧页面请求覆盖新页面。自动更新默认关闭，工作台登录记忆有效期固定为 30 分钟；恢复登录的慢响应不能撤销退出操作。
- 费用基于调用时保存的价目与完整用量估算，不等于实际账单；完整口径见 [用量专题](usage-monitoring.md)。
- 页面存在独立的 Prompt、素材、请求和用量视图模块；代码导航见 [架构与开发](architecture.md#代码放在哪里)。
