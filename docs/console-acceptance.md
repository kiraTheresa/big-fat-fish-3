# 管理台人工验收清单

本清单覆盖 `web/` 管理台与实际管理 API 的业务链。隔离浏览器检查与真实 QQ / 模型验收分开记录；下方业务清单仍用于真实环境人工验收。页面没有示例业务数据；卡片、列表和详情均读取同源 API。

## 启动与范围

1. 在本地 `.env` 设置随机 `ADMIN_TOKEN`，至少 24 个字符；不要把令牌写入文档、聊天或 URL。
2. 使用 `npm start` 启动 Bot。默认管理地址为 `http://127.0.0.1:3210`，以启动日志中实际端口为准。
3. 在页面输入管理令牌。验证成功后在当前浏览器记住登录 30 分钟，期间刷新或重新打开会自动验证令牌并进入；刷新不续期。退出、到期或 401 会清除记录。浏览器禁用存储时退回只保留页面内存，并显示提示。
4. 当前网页是 QQ Bot 的本地控制台，功能包含概览、事件收件箱、配置、用户权限、调度、日志和用量。任务类型只有数据维护与记忆提炼，不提供主动发消息入口。

## 设计与维护约定

- 开发阶段功能优先：灰白实色面板、清晰边框、紧凑表格，蓝色标识选中项与主要操作。导航按运行排查、开发调试、实例管理分组。没有外部素材、字体或图片依赖。
- `index.html` 提供登录页与稳定布局；`app.js` 管理路由、真实 API、表单与错误状态；`styles.css` 管理响应式样式。
- API 动态内容统一 HTML 转义，JSON 详情作为文本展示。静态站点兼容 `script-src 'self'; style-src 'self'`。
- 状态刷新具有请求序号保护，避免旧页面请求覆盖新页面。自动更新默认关闭，工作台登录记忆有效期固定为 30 分钟；恢复登录的慢响应不能撤销退出操作。
- 不支持模型价格换算，所以不展示费用估算。上游未返回的用量明确显示未知。
