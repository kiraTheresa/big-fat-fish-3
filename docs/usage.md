# 和肥鱼聊天

[← 文档目录](README.md)

## 怎么叫本鱼

- **私聊**：直接发消息；开启识图时也可以只发图片。
- **群聊**：@ 本鱼、喊“大肥鱼／肥鱼”，或引用本鱼已发送的消息；三种唤醒方式可以分别开关，名字可以配置。单独 @ 也会回应。
- **戳一戳**：戳机器人时生成一句短回复；不调用绘图或表情工具。戳别人不会让本鱼插话。
- **指令**：群聊要真正 @ 本鱼，私聊直接发送。`ping` 是连通性检查的例外，群里也不需要 @。

聊天和戳一戳共用会话冷却，默认 2 秒，窗口内的新触发会静默跳过。普通回复可配置随机延迟、分段和群聊引用；开关、权限和额度也会影响是否回复。群聊引用唤醒依赖本进程记住的已发送消息 ID，重启后不保留旧 ID。

## 看图与画画

看图时优先使用当前消息的一张图片；否则可接着看同一会话、同一用户最近发的图片，默认时间窗为 120 秒。私聊从本地历史找近图，群聊通过 NapCat 查询近图，群聊仍需符合唤醒条件。每轮最多附带一张图片；模型需支持图片输入，下载或带图请求失败时可回退文字回复。

画画可以直接说“帮我画一只戴围巾的猫”，或发送 `/draw 一只戴围巾的猫，水彩风格`。自然语言绘图由模型选择工具；`/draw` 直接进入绘图流程。需配置绘图接口并启用能力，群聊指令仍需 @；默认不限制绘图 QQ 白名单。

生成的原图和提示词会自动存到本地媒体目录，工作台“绘图作品”页可查看和下载。保存失败时会记录警告，已生成的图片仍尝试发送。详见 [媒体存储](media-storage.md)。

## 人设与记忆

每个群共享一份人设和记忆，每段私聊各自独立。上下文是近期对话；长期记忆另存为文件，可以通过自然语言工具或 `/remember` 明确保存事实，用 `/character` 教一种说话方式。

```text
/remember 小明不吃香菜
/character 回答技术问题时先给结论
/memory
/persona
```

这两个教学指令直接写文件，不调用模型。后台提炼会调用模型整理人设和记忆，保留输入快照中的锁定条目；群聊默认两小时无人有效调用后休眠，再次调用恢复。提炼不是无限保存全部聊天，文件有容量限制。具体调度、锁定校验和退避见 [管理文档](management.md)。

`/reset` 只重置聊天上下文的可见水位，不删除历史文件，也不清空长期记忆。`/persona reset` 会恢复初始人设并清空记忆。修改工作台里的“初始人设”只作用于新建或重置会话，不覆盖已有会话，见 [Prompt 工作台](prompt-console.md)。

## 指令速查

下表中的指令在群聊都需要 @；标为“会话管理”的操作，群聊要求肥鱼管理员权限，私聊可以管理自己的会话。

| 指令 | 作用 | 权限 |
| --- | --- | --- |
| `/help` | 查看普通指令帮助；绘图用法见本页，表情子指令见 `/meme help` | 普通用户 |
| `/status` | 查看人设／记忆大小、会话用量与待提炼状态 | 普通用户 |
| `/version` | 查看从更新日志读取的版本 | 普通用户 |
| `/draw 描述` | 按描述生成图片 | 普通用户，需启用绘图 |
| `/persona`、`/memory` | 查看当前人设或记忆 | 普通用户 |
| `/remember 内容` | 保存一条事实记忆 | 普通用户 |
| `/character 内容` | 追加性格或说话方式 | 普通用户 |
| `/reset` | 重置聊天上下文 | 会话管理 |
| `/persona reset` | 恢复初始人设并清空记忆 | 会话管理 |
| `/history` | 查看最近的人设变动审计 | 会话管理 |
| `/meme help`、`/表情 help` | 查看表情包收藏、查找、发送及管理用法 | 子指令分别检查权限 |

表情也支持附图或引用后说“这个表情失落的时候用它”，以及“发一个躺平的表情”。收藏按会话隔离，不会自动收走聊天里的每张图；改名、停用和恢复使用明确指令。完整操作见 [表情手册](memes.md)。

QQ 角色和工作台登录是两套权限：成为肥鱼管理员不等于获得网页权限。封禁用户的事件仍收件，但不进入聊天处理；详见 [权限说明](management.md#权限)。
