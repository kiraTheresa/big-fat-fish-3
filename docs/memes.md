# 肥鱼表情包

肥鱼只有一个共享表情库：在任意群聊或私聊里收藏后，都能在其他群聊和私聊中检索、发送。素材文件位于 `DATA_DIR/media/memes`，共享名称、使用记录和停用状态由本地索引保存。来源会话只用于追溯和 Web 筛选。自动收集未开启；别人随手发图不会让肥鱼自动入库。

## 先教肥鱼收藏，再让它用

最直接的操作是引用一条表情消息，私聊输入：

```text
/meme save 躺平，不想干活，适合轻松自嘲
```

也可以把这句指令与一张表情一起发送。群聊需要同时 @ 肥鱼。一次只收一张；有多个候选时请拆开或引用准确的一条。名称可以直接写出表情含义，方便以后搜索。成功回复会给出收藏 ID；重复收藏会复用已有条目。保存不完整时不会假装已经可以原样发送。

```text
/meme list 躺平
/meme send 完整表情ID
```

`send` 也接受唯一且完全匹配的名称，例如名称仅为“躺平”时可用 `/meme send 躺平`。同名或找不到时会提示使用 ID。发送成功时表情本身就是回复，不再额外发一句“发送成功”。失败不自动重试。

## 自然语言工具

聊天模型可用三项表情工具：`save_meme` 收藏当前用户明确要求保存的表情，`search_memes` 按意思寻找共享库里的少量候选，`send_meme` 发送选中的收藏。工具的开关和描述在 Prompt 工具配置中管理，显式指令遵守同一开关。

自然语言工具目前只支持收藏、查找和发送。修改名称、停用、恢复需使用下方的明确管理指令，不能只说一句“改名了”就视为操作完成。

可以引用表情说“肥鱼，收下这个，这是累得不想动”，也可以直接教用途：“这个表情包失落的时候用它”“以后加班用这个”。当前用户附上或引用表情并教用途、情绪或名字，也属于收藏请求；必须执行 `save_meme` 后按结果确认。单纯讨论、用法问句、否定收藏或引用别人的要求不自动保存。

需要使用时可以说“发一个躺平的表情”。只说“肥鱼出来发个表情包”或“随便来一个”时，模型用“全部”查询可用收藏，再选择一个发送；明确指定主题时仍按主题检索，没有匹配不会拿无关表情冒充。正常聊天中，肥鱼也可以在轻松接梗时选择已有表情，不要求每次回复都用。它仍遵守原有唤醒规则：不会因为群里有人随口说了一句话就新增一次主动发言。模型选择是否调用工具，因此自然语言理解效果依赖实际模型；明确的 `/meme` 指令可用于稳定操作。

查找结果只包含名称、标签、ID 等挑选信息，不把原生表情 key、下载地址或全部图片交给模型。没有合适候选可以不用；找到了也不代表必须发送。工具返回发送确认后才能声称发出，平台确认不等于对方客户端已经播放动画。

每轮自然语言回复最多收藏一次、查询一次、尝试发送一个表情；失败也占用本轮发送机会，不换 ID 连续补发。共享库新增收藏上限为 5000 个；跨群聊、私聊按内容去重，重新收藏可补全商城参数、更新失效 key 或修复损坏素材。名称/含义和标签参与关键词、中文分词及双字匹配，近期使用的候选适当降权；这是本地检索，不是视觉识别或向量语义搜索。

升级时会为旧 Prompt 配置补入三个表情工具和对应使用规则；用途教学修复仅替换逐字匹配的旧内置表情规则及默认工具描述，保留定制正文以及已有工具开关。草稿内容变化时生成新 revision，旧评审不再适用于新草稿，但历史测试记录保留。Prompt 控制台中的模拟模式和真实模型测试模式都不会通过表情工具修改线上收藏或发往 QQ。

旧版按会话分开的收藏会在启动时迁入共享目录，迁移前备份旧索引；保留原表情 ID、名称、状态、使用记录和原始文件。历史上不同 ID 的重复素材仍保留，避免旧 ID 失效；后续收藏在共享库中去重。收藏引用仍只读取当前消息或本会话的引用消息，发送目标也始终是当前会话。

## 常用管理指令

| 指令 | 用途 |
| --- | --- |
| `/meme help` 或 `/表情 help` | 查看用法 |
| `/meme save 名称或含义` | 收藏随消息附带或引用的一张表情 |
| `/meme list [关键词]` | 最多列出 10 个匹配收藏，含停用/不完整标记 |
| `/meme send 名称或ID` | 向当前会话发送共享库可用的收藏 |
| `/meme rename ID 新名称` | 修正名称和含义 |
| `/meme disable ID` | 停用但保留收藏与文件 |
| `/meme enable ID` | 恢复使用 |

改名、停用、恢复会影响整个共享库，因此在群聊和私聊中都要求肥鱼管理员权限（不等同于任意 QQ 群成员）。普通用户可以收藏、查找和请求发送；封禁规则仍由统一入口执行。

## 动画与原生表情

- 自定义图片表情：保存原始图片字节和发送属性，GIF 不转成静态图。
- QQ 商城表情：保存 `mface` 原生引用，发送时使用原生消息段；本地图片不是必需品。
- QQ 内置表情：保存 `face` 参数，按对应类型发送。
- 预览图不替代发送原图。缺失、过期或损坏的资源不能保证可发送，也不会静默改成普通缩略图。

参数完整性和本地自动化测试不能证明所有 QQ 客户端的实际动画呈现。上线验收应分别用一张 GIF、一个商城表情和一个内置表情执行“收藏 → 查找 → 发送”，检查实际客户端的内容与动画。实现及存储细节见 [媒体文件存储](media-storage.md)。
