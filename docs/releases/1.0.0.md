# 大肥鱼 1.0.0

首个稳定版本。大肥鱼可以被动回应 QQ 私聊、群聊唤醒和戳一戳，支持识图、绘图、共享表情、会话人设与长期记忆。工作台提供 Prompt 草稿、快照试聊、评审和发布，以及用量、请求链路、权限与后台任务管理。

相较于 0.36.0 公开测试版，本版整理了管理台导航和 Prompt 工作台，为近期聊天保留上下文预算，并细化默认人设、精简消息和工具提示。 `main` 的 CI 覆盖 Node 22 测试与 Docker Compose 构建和启动检查。 [完整更新日志](../../CHANGELOG.md)

## 升级

1. 停止旧 Bot，备份 `.env`、`config.json`、`data/` 和 `napcat/`。自定义的人设、用量和数据目录也应一并备份。
2. 切换到 `v1.0.0`。确认 `config.json` 是文件，且容器用户可写入 `data/`。
3. NapCat 的 6099 和 3001 现在默认仅绑定本机。如果原来通过可信局域网使用这两个端口，先将 `NAPCAT_BIND_HOST` 设为宿主的局域网 IP。肥鱼工作台的宿主访问端口由 `ADMIN_PUBLISH_PORT` 控制。
4. 在项目根目录运行 `docker compose up -d --build`，查看 `docker compose ps` 和 Bot 启动日志。随后打开工作台核对连接和配置，按需在 QQ 发送 `ping` 并验证模型回复。 [部署与排查](../napcat-deployment.md)

既有工作台已发布的 Prompt 和会话人设优先于仓库默认模板。已有部署可以在工作台载入草稿、试聊并评审后发布。初始角色模板在新建或重置会话时使用。 [Prompt 生效范围](../prompt-console.md#人设与记忆的作用范围)
