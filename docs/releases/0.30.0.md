## 发布介绍

大肥鱼是一个可自托管的 QQ 聊天机器人，基于 NapCat、OneBot 11 和 Node.js。它能聊天、看图、画画、保存长期记忆，也能收藏并发送共享表情；本地工作台用于照看运行状态和调整提示词。

这是首个计划通过 GitHub Release 提供的公开测试版，汇总此前开发版本的功能。欢迎尝试部署并反馈问题；模型效果、供应商兼容性和真实 QQ 客户端表现仍需要更多实际使用验证。

## 主要内容

- 群聊 @、呼唤名字、引用回复与戳一戳；私聊支持纯图片及近图追问。聊天和识图流式接收完成后再向 QQ 回复。
- 按群聊／私聊隔离的人设和长期记忆，支持明确教学与后台提炼；群聊闲置后暂停提炼。
- 指令及自然语言绘图、进度提示、原图归档；工作台浏览和下载作品。
- 跨会话共享表情库，支持收藏、检索、原生发送及管理员改名、停用、恢复。GIF 原始字节与 QQ 原生引用分别保存。
- Prompt 编辑、请求预览、会话快照测试、人工评审、发布及通过草稿回退；默认正文独立存放。
- 本地管理工作台涵盖事件、配置、QQ 权限、调度、日志、用量和素材浏览；浏览器固定记住登录 30 分钟。

## 安装与升级

首次安装按 [部署文档](../napcat-deployment.md) 操作：准备 Docker Compose、QQ 账号和兼容模型接口，从示例生成配置，填写令牌及实际模型参数后启动。模板默认模型名不代表供应商必然支持。

已有部署升级前停止 Bot，备份 `.env`、`config.json`、完整 `data/` 和 `napcat/`；自定义人设、用量等目录也要备份。保留 QQ 登录目录与固定 hostname。

取得本版本源码后，在项目根目录运行 `docker compose up -d --build bot`。仅升级 Bot 不必重建 NapCat。若同时改变连接令牌，按部署文档同步更新 NapCat。

- 旧会话表情索引自动备份并迁入共享库；来源会话仅用于追溯，各会话现在可以检索和发送同一收藏。
- 已保存的工作台配置、定制 Prompt 与已有会话人设保留；默认模板更新不会全面覆盖线上发布配置。内置表情规则的定向迁移见 [表情手册](../memes.md)。
- 修改初始人设仅作用于新建或重置会话。不要用重置会话升级人设，重置会清空该会话记忆。
- 回退前停止 Bot，恢复旧源码与对应的完整数据备份；不能假定旧版能读取迁移后的索引。
- 启动后检查连接状态及 `/version`，预期返回 `0.30.0`。

## 已知边界

- 语音、视频、文件、好友／入群申请主要只收件；没有定时主动发 QQ 消息功能。
- 模型选择工具和回复质量不是确定性保证；支持的操作可优先用明确指令。文字、识图、提炼共享模型，绘图使用独立接口。
- 原生表情参数完整、平台发送确认或网页预览，均不能证明客户端动画播放正常；引用也可能过期。
- 单实例运行；发送队列在内存中，历史记录不等于已送达。媒体长期保存，暂时没有自动容量淘汰。
- 用量统计不等于供应商账单，token 阈值也不是硬性金额上限。
