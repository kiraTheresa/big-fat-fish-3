# Prompt Studio V3 · 模块卡片工作台

体验：<http://localhost:4173/v3/>。沿用 V2 的静态服务，无需安装或构建。

- 默认按模块卡片阅读完整 context，切到「原始 JSON」查看同一份请求。
- 阅读与编辑沿用相同的模块边界，所有正文连续展开；目录仅用于定位。
- 运行台以输入、请求快照、输出三张卡片组织，也可切到 JSON 阅读。
- 运行快照同时保留原始请求和模块正文，后续编辑不会改变已捕获的内容。
- 复用 V2 的请求组装器和基础样式，V3 草稿独立保存在 `fish.prompt-studio.demo.v3`。

本地交互 demo，回复为预设，不发送 API / QQ 请求。未接入正式 builder。
本轮不跑自动化测试或完整验收；先用于看页面、讨论和迭代。V2 保留在 `/v2/`。
