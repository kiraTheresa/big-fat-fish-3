# Context Workbench V2

日期：2026-11-04。独立前端原型，尚未接入正式 Bot。

启动方式沿用上一级原型，在仓库根目录运行：

```sh
python3 -m http.server 4173 --bind 127.0.0.1 --directory demos/prompt-studio
```

打开 <http://localhost:4173/v2/>。V1 仍在根路径，V2 复用其示例积木文件，不读取 V1 的浏览器草稿。V2 独立使用 localStorage 键 `fish.prompt-studio.demo.v2`。

## 本轮设计修正

用户希望看到整个上下文，以及 OpenAI 规范下最原始的请求结构，交互生命周期为单次调用。

- **检查请求（默认，只读）**：完整 JSON 常驻主区域，不折叠、不截断；另有连续正文，依次展示所有 messages 和 tools。编辑入口与只读展示分开。
- **编辑积木**：所有正文在一个连续文档中展开。左侧目录只滚动定位，不切换或隐藏其他块。支持添加/替换、启停、按钮排序、移除和上次结构恢复。
- **单次运行台**：CLI 式命令、组装状态与 stdout。每次运行替换上次记录，输入和输出不会自动进入下次请求。
- **当前组装与运行快照**：编辑后当前组装更新，运行时捕获的 request 不变；明确标记快照过时。
- **复制/下载**：得到与 JSON 视图相同的请求 body，不附带编排元数据，不包含密钥或认证头。
- **简约工作台**：取消聊天气泡、装饰侧栏和大标题。窄屏在上下文与运行台之间切换，编辑时依然保留全部积木正文。

不把“所有内容同时存在”解释为“所有内容必须挤进首屏”。主文档统一滚动，长字符串自然换行，不强制切换积木才能看到其他内容。

## 请求结构

字段根据 [OpenAI 官方 Chat Completions 文档](https://developers.openai.com/api/reference/resources/chat/subresources/completions/methods/create)核对；项目现有请求路径同样采用 Chat Completions，并非 Responses。

- 固定规则、人设、回应方式、记忆素材、工具使用策略按顺序编入一个 `system.content`。
- 近期历史为独立 `user` / `assistant` 消息；编辑时使用 JSON 数组，格式非法会明确阻止请求组装。历史不允许额外 `system` 角色。
- 本轮输入是末尾一条 `user`。不会把上次 stdout 加入数组。
- 函数工具在独立 `tools` 数组中，采用 `type: function`、`function.name` 和 JSON Schema `parameters`。
- 模型名采用项目当前默认示例 `deepseek-flash`，并非宣称该名称是 OpenAI 模型。流式字段沿用现有网关的结构。
- `request.js` 是原型专用的纯组装函数；JSON、连续正文、复制、下载和运行快照都使用它。未接入生产 `src/prompt/builder.js`，也不等于抓取了线上真实请求。

## 原型边界

只使用本地虚构素材。没有真实模型、QQ、持久化后端、记忆检索、工具执行、迁移或发布；stdout 为场景预设或自定义输入的说明，不能判断 Prompt 的实际效果。没有 token 精算或供应商上限验证，页面仅显示实际序列化 UTF-8 字节数。

V2 不增加自由画布、复杂连线、多轮聊天管理、版本发布或 V1 的快照比较。需要比较旧方向时直接回到 V1。

“还原上次结构”保留一份操作前的积木副本，恢复时交换两份结构；再次点击可以回到恢复前，避免替换/移除后丢失编辑。

## 验证

```sh
node --test demos/prompt-studio/v2/request.test.js
node --check demos/prompt-studio/v2/workbench.js
```

定向测试覆盖正文与角色原样保留、关闭的块不进入请求、工具 schema、无工具时省略字段、单次输入隔离、捕获结果不随草稿变化、无效历史/越权历史角色/空模型拒绝。

浏览器实际检查：

| 检查 | 结果 |
| --- | --- |
| 只读 JSON | 页面正文可直接 JSON.parse，包含 5 条消息和默认 5 项函数工具；上下文编辑器为 0 个 |
| 编辑与全文 | 一次展开 6 个积木编辑器；修改同步进入 JSON；连续正文包含全部消息和工具 |
| 单次执行 | 两次运行分别捕获请求，第二次不含第一次输入或输出；旧快照不随输入编辑变化 |
| 错误路径 | 空输入有提示；无效/越权角色历史阻止组装；空模型阻止执行 |
| 工具开关 | 关闭记忆工具后 JSON 只保留 3 项表情工具 |
| 结构操作 | 角色替换、排序与恢复实际通过；正文未丢失 |
| 复制 | 浏览器剪贴板中的完整 JSON 可解析，消息数与页面一致 |
| 窄屏 | 390px 请求/运行台切换通过；编辑仍包含全部 6 块；390 / 960 / 1440px 无页面水平溢出 |
| 控制台 | 本轮检查 error / warn 为空 |

浏览器控制连接曾暂时失效，重新初始化后恢复，以上均为恢复后实际检查。截图为 `fish-studio-v2-json.jpg`、`fish-studio-v2-edit.jpg` 与 `fish-studio-v2-mobile.jpg`，保存在本次聊天的可视化目录。

未做真实模型/QQ 调用、正式后端接入、全量回归、下载文件校验与存储不可用故障注入。以上不代表真实模型或 QQ 效果验收。
