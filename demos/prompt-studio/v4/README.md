# Prompt 工作台 V4

体验地址：<http://localhost:4173/v4/>，沿用已有静态服务，无构建步骤。

- 沿用正式产品的左侧页面导航与顶部页面信息骨架；其他页面是导航占位。
- 页面只有一处正文 / 完整请求 JSON 切换，编辑时仍保留；JSON 是只读组装结果。
- Edit / Save / 取消在原地工作。保存仅更新浏览器草稿，编辑内容可直接参与模拟；取消还原配置，保留试聊输入。
- 角色模板跨工作区复用；会话变化按工作区和角色区分；临时扮演独立启停，退出不改写角色模板或事实记忆。
- 作用范围面板说明人设与各提示词的关系；戳一戳和后台提炼仅表达设计边界，没有接入执行。
- 右侧只做单次试聊，不切换正文 / JSON、不展示局部输入 JSON。完整请求在主区域查看；最近一次请求快照收在底部高级区。
- 使用 V2 的请求组装器和既有样例；V4 草稿存储于 `fish.prompt-studio.demo.v4`，不修改旧版草稿。

本地前端 demo，预设输出不能用来评估真实人设效果，不调用 API / QQ，不接入正式发布。
按本轮要求未运行测试或完整验收；用于直接体验布局和交互。
